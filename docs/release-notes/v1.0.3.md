Sürüm 1.0.3. Legend "Hızlı Başlat" panelindeki etiket çakışması giderildi ve paket adları artık sürüm numarasını izliyor. KADRAJ ile video indirme, ses kaydı, video düzenleme, fotoğraf üretimi, dizi/film hazırlama ve ayarları tek uygulamada kullanabilirsiniz.

### Değişiklikler

- Legend "Hızlı Başlat" panelinde "Video Düzenle" gibi etiketler kısayol yazısının (Ctrl+3) üstüne biniyordu. Kartlar genişletildi; etiketler artık kısayolla çakışmıyor.
- Windows'ta sürükle-bırak ile gelen dosya yolları Windows biçiminde işleniyor.
- Paket dosya adları sürüm numarasını `kadraj/version.py` dosyasından alıyor. Önceki sürümün (1.0.2) paketleri yanlışlıkla 0.1.0 adıyla çıkmıştı; bu sürümde adlar 1.0.3.
- Paketleme iş akışı (GitHub Actions) güncellendi.

### Hangi dosyayı indirmeliyim?

| Sistem | İndirilecek dosya |
|---|---|
| Linux (x86_64) | `KADRAJ-1.0.3-linux-x86_64.tar.gz` (yanındaki `.sha256` ile doğrulayabilirsiniz) |
| Windows 10/11 (64 bit) | `KADRAJ-1.0.3-windows-x64-setup.exe` |
| — | Sayfanın altındaki "Source code" bağlantıları GitHub'ın her sürüme otomatik eklediği ham kaynak koddur; kurulum için gerekmez. |

### Kurulum

**Linux**

```bash
tar -xzf KADRAJ-1.0.3-linux-x86_64.tar.gz
cd KADRAJ-1.0.3-linux-x86_64
./install.sh
```

Kısayol ve `kadraj` komutu eklenir; `sudo` gerekmez. Kaldırmak için `./uninstall.sh` çalıştırın. Verileriniz (`~/.kadraj`) silinmez.

**Windows**

1. `KADRAJ-1.0.3-windows-x64-setup.exe` dosyasına çift tıklayın. Yönetici izni gerekmez.
2. "Bilgisayarınız korundu" uyarısı çıkarsa "Ek bilgi" → "Yine de çalıştır" seçin. Uyarı, dosyanın imzasız olmasından kaynaklanır.
3. Kaldırmak için Ayarlar → Uygulamalar → KADRAJ → Kaldır. Verileriniz (`%USERPROFILE%\.kadraj`) korunur.

### Gereksinimler

- Linux: x86_64, glibc 2.34 veya üstü (Ubuntu 22.04+, Debian 12+, Fedora 35+, Arch / CachyOS); `ffmpeg`, `libportaudio2`, `libxcb-cursor0`
- Windows: 10 veya 11, 64 bit; FFmpeg için `winget install Gyan.FFmpeg`

### Bilinen sınırlar

- Bulut yapay zekâ sağlayıcıları, Ollama ve ComfyUI gerçek hizmetlerde henüz sınanmadı.
- Gerçek Whisper modeli, librosa, OpenCV ve rembg özellikleri henüz sınanmadı.
- VAAPI ile video render ve Wayland ekran kaydı henüz gerçek donanımda sınanmadı.
- Linux paketi Ubuntu 22.04 ve CachyOS üzerinde sınandı; Fedora, Debian ve Arch'ta henüz denenmedi.
- Windows paketi GitHub Actions'ta derlenir. Paketlenmiş uygulamanın açılış sınaması (selftest) ve sessiz kurulum, çalıştırma ve kaldırma denemesi derlemenin kapısıdır. Gerçek bir Windows bilgisayarında henüz denenmedi.
- macOS paketi henüz yok.
